Setting up this site and the /note workflow

Nov 18, 2026

What I built

A static GitHub Pages site: index.html plus style.css, with a notes section under notes/. No build step, so pushing to main publishes it.

Publishing notes from any repo

A helper script, scripts/new-note.sh, reads an HTML body from stdin, writes notes/<slug>.html and adds an entry at the top of the notes index. A /note Claude Code skill clones this repo into a temp directory, runs the script, then commits and pushes.

Gotchas

  • Inside the sandbox, SSH remotes fail. Pushing over HTTPS works once a GitHub token is set as a sandbox secret.
  • Skills are loaded at session start, so a newly installed skill only appears after restarting Claude Code.
